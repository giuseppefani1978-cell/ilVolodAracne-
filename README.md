## 🇬🇧 English

### About the Project
**IL VOLO D'ARACNE** is a mobile-friendly, single-page web application designed to help users plan custom itineraries in the beautiful region of Salento, Puglia (Italy). 

The app features an interactive map pre-loaded with 50 Points of Interest (POIs). Users can create routes step-by-step, calculate distances and travel times, add custom notes and stop durations, and easily share their final itinerary via WhatsApp or open it directly in Google Maps.

### ✨ Features
- **Interactive Map:** Powered by Leaflet and OpenStreetMap, centered on Salento.
- **Pre-loaded POIs:** 50 popular locations ready to be added to your route.
- **Route Calculation:** Switch between **Driving/Scooter** and **Walking** modes (powered by OSRM).
- **Custom Waypoints:** Tap anywhere on the map to add custom stops.
- **Time & Distance Management:** Calculates travel time, distance per leg, and total journey time (including custom stop durations for each location).
- **Retractable Dashboard:** Easily hide the planner to view the map in full screen.
- **Export & Share:** Generate a Google Maps link for navigation or share a detailed summary via WhatsApp.
- **Multi-language UI:** Automatically detects browser language (supports EN, IT, FR).

### 🚀 How to Use / Deployment
Since this is a standalone HTML file, no backend or database is required.
1. Download the `.html` file.
2. Open it directly in any web browser.
3. For deployment, simply host the file on **GitHub Pages**, **Netlify**, or any basic web server.

## 🇮🇹 Italiano

### Informazioni sul Progetto
**IL VOLO D'ARACNE** è un'applicazione web single-page ottimizzata per smartphone, pensata per aiutare gli utenti a pianificare itinerari personalizzati nella splendida regione del Salento, in Puglia.

L'app offre una mappa interattiva con 50 Punti di Interesse (POI) precaricati. Gli utenti possono creare percorsi tappa dopo tappa, calcolare distanze e tempi di percorrenza, aggiungere note personali e tempi di sosta, e infine condividere l'itinerario completo tramite WhatsApp o aprirlo su Google Maps.

### ✨ Funzionalità
- **Mappa Interattiva:** Basata su Leaflet e OpenStreetMap, centrata sul Salento.
- **POI Precaricati:** 50 luoghi iconici pronti per essere aggiunti al tuo percorso.
- **Calcolo del Percorso:** Scegli tra modalità **Auto/Scooter** e **A piedi** (tramite OSRM).
- **Tappe Personalizzate:** Tocca qualsiasi punto sulla mappa per aggiungere una tappa.
- **Gestione Tempi e Distanze:** Calcola il tempo di viaggio, la distanza per ogni tratta e il totale del viaggio (inclusi i tempi di sosta personalizzati per ogni tappa).
- **Dashboard a Scomparsa:** Nascondi facilmente il pannello per visualizzare la mappa a schermo intero.
- **Esporta e Condividi:** Genera un link di Google Maps per la navigazione o condividi il riepilogo dettagliato su WhatsApp.
- **Interfaccia Multilingua:** Rileva automaticamente la lingua del browser (supporta IT, EN, FR).

### 🚀 Come Usare / Pubblicazione
Poiché si tratta di un singolo file HTML, non è richiesto alcun backend o database.
1. Scarica il file `.html`.
2. Aprilo direttamente in qualsiasi browser web.
3. Per la pubblicazione online, è sufficiente ospitare il file su **GitHub Pages**, **Netlify** o qualsiasi server web di base.

## 🇫🇷 Français

### À propos du projet
**IL VOLO D'ARACNE** est une application web monopage, adaptée aux smartphones, conçue pour aider les utilisateurs à planifier des itinéraires personnalisés dans la magnifique région du Salento, dans les Pouilles (Italie).

L'application propose une carte interactive préchargée avec 50 points d'intérêt (POI). Les utilisateurs peuvent créer des itinéraires étape par étape, calculer les distances et les temps de trajet, ajouter des notes personnelles et des temps de pause, et enfin partager l'itinéraire complet via WhatsApp ou l'ouvrir dans Google Maps.

### ✨ Fonctionnalités
- **Carte Interactive :** Basée sur Leaflet et OpenStreetMap, centrée sur le Salento.
- **POI Préchargés :** 50 lieux emblématiques prêts à être ajoutés à votre itinéraire.
- **Calcul d'Itinéraire :** Basculez entre les modes **Voiture/Scooter** et **À pied** (via OSRM).
- **Étapes Personnalisées :** Touchez n'importe quel endroit sur la carte pour ajouter une étape libre.
- **Gestion du Temps et de la Distance :** Calcule le temps de trajet, la distance par étape et le temps total du voyage (incluant les temps de pause définis pour chaque étape).
- **Tableau de Bord Rétractable :** Masquez facilement le planificateur pour voir la carte en plein écran.
- **Exportation & Partage :** Générez un lien Google Maps pour la navigation ou partagez un résumé détaillé via WhatsApp.
- **Interface Multilingue :** Détecte automatiquement la langue du navigateur (prend en charge FR, EN, IT).

### 🚀 Comment l'utiliser / Déploiement
Comme il s'agit d'un fichier HTML autonome, aucun backend ou base de données n'est requis.
1. Téléchargez le fichier `.html`.
2. Ouvrez-le directement dans n'importe quel navigateur web.
3. Pour le mettre en ligne, il suffit d'héberger le fichier sur **GitHub Pages**, **Netlify** ou tout serveur web basique.
